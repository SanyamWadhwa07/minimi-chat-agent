# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be welcoming and patient, assume good intent, give and accept constructive criticism
gracefully, and focus on what is best for the people who use and build this project. Harassment,
insults, personal attacks, and publishing other people's private information are not accepted.

## Reporting

Report unacceptable behaviour privately to the maintainer,
[@SanyamWadhwa07](https://github.com/SanyamWadhwa07), using the contact details on their GitHub
profile. Reports are handled promptly and confidentially.
